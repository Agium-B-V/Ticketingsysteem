# Agium Ticketing

Een laagdrempelig ticketsysteem waarmee iedereen bij Agium vragen aan Finance en IT kan stellen. De app is een statische Vite + React-app met Supabase als database en voor het inloggen.

De volledige handleiding volgt in fase 5 van de bouw.

## Lokaal starten

```bash
npm install
cp .env.example .env.local
npm run dev
```
